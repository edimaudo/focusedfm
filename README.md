# focusedfm

focusedfm is a productivity tool that helps you focus. It is built In line with the principle that playing regular lyrical music distracts rather than focuses the mind.

## Project Structure
```
focusedfm/
├── app.py
├── vercel.json
├── requirements.txt
├── static/
│   ├── css/
│   │   └── style.css
│   └── js/
│       └── player.js
└── templates/
    ├── base.html
    └── index.html
```
