# focusedfm

focusedfm is music to help you focus. It's built with the principle that playing regular lyrical music distracts rather than focuses the mind.

## Project Structure
```
focusedfm/
├── app.py
├── vercel.json
├── requirements.txt
├── static/
│   ├── css/
│   │   └── style.css
│   └── js/
│       └── player.js
└── templates/
    ├── base.html
    └── index.html
```
